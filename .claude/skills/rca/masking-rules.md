# RCA 리포트 마스킹 규칙

리포트(`docs/rca/*.md`)를 저장하기 전에 리포트 전체에 적용한다. 원본 로그 파일은 고치지 않는다.

| 유형 | 규칙 | 예 |
|---|---|---|
| IP 주소 | 앞 두 옥텟만 남기고 나머지는 `x` | `10.20.x.x` |
| IP 주소(구분이 필요한 값) | 응답한 서버 · 연결을 거부한 서버 · 반복 요청한 단말처럼 구분이 분석에 필요하면 역할 별칭 | `API-1`, `API-2`, `교사단말A`, `교사단말B` |
| 이메일 | 아이디를 `***` 로, 도메인은 유지 | `***@example.com` |
| 학생 식별자(`STU-<숫자>`) | 등장 순서대로 별칭. 같은 학생은 끝까지 같은 별칭 | `학생A`, `학생B` |
| 토큰 · 세션 ID · API 키 · Authorization 헤더 값 | 값 전체를 치환 | `[TOKEN]` |
| 비밀번호 · 접속 문자열 | 값 전체를 치환 | `[SECRET]` |

- 적용 후 리포트 맨 아래에 "마스킹 적용: 유형별 건수"를 한 줄로 남긴다.
- 원본과 별칭의 대응표는 리포트에도, 다른 파일에도, 대화에도 남기지 않는다.
- 마스킹 전 원본을 임시 폴더에 복사해 두지 않는다.
- 확인: 아래 패턴은 원본 로그에서 0이 아닌 건수가 나와야 하고, 리포트에서는 아무것도 나오지 않아야 한다.
  `([0-9]{1,3}\.){3}[0-9]{1,3}|[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[a-z]{2,}|STU-[0-9]+|Bearer [A-Za-z0-9._-]{8,}`
